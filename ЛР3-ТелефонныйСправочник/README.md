# Лабораторная работа №3: Телефонный справочник

**Студент:** Сердюк А.А. 
**Группа:** ИСП 11-51  
**Язык:** C# (.NET 8.0)

## Постановка задачи
Разработать консольное приложение «Телефонный справочник» для хранения и управления контактами. Программа поддерживает добавление, просмотр, поиск и удаление контактов, а также сохраняет данные между запусками в файле формата JSON.

## Инструкция по запуску
1. Установите .NET SDK 8.0: https://dotnet.microsoft.com/download
2. Перейдите в папку `src`: `cd src`
3. Запустите программу: `dotnet run`

## Формат файла с данными
Данные хранятся в файле `data/contacts.json` в формате JSON. Ключ словаря — имя контакта, значение — объект с полями `Name` и `Phone`. Пример:
```json
{
  "Иван Иванов": { "Name": "Иван Иванов", "Phone": "+7 (900) 123-45-67" }
}
